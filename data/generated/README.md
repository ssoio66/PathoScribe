# Generated pathology workflow data

Run `npm.cmd run data:generate:pathology-workflow` to create the nine JSON tables and the web preview in this directory.

The generated files are local artifacts and are excluded from Git until the source redistribution terms are confirmed. Every `ORD/SPC/GRS/BLK/RPT/IHC/MOL/EXT/REV-LUNG-2026-*` identifier and every row marked `generated_demo` is fictional. Do not use this dataset for diagnosis, interpretation, or production hospital-system linkage.
