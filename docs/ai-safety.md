# AI 안전정책

## 적용 목적

AI는 병리 전사 담당자의 입력과 원문 대조를 돕는 초안 도구입니다. 진단, 판독, 병기 판정, 예후 예측, 치료 추천 또는 공식 의료기록 확정에 사용하지 않습니다.

## Gemini 구조화 원칙

- Gemini는 `app/api/analyze/route.ts`에서 서버 전용으로 호출합니다.
- 원문에 명시된 정보만 추출합니다.
- 원문에 없는 값은 `null`로 둡니다. 원문에 값이 있지만 서로 충돌하거나 결과 형식이 불완전한 경우에는 발견한 값과 `evidenceText`를 보존하고 `needs_review`로 둡니다.
- 각 필드는 `value`, `evidenceText`, `status`를 포함하는 JSON Schema를 통과해야 합니다.
- Gemini의 자기신고 confidence는 보정된 신뢰도 정보가 아니므로 응답에 사용하지 않습니다.
- 허용되지 않은 필드, 중복·누락된 필드, 잘못된 상태값, 형식이 깨진 응답은 거부합니다.
- `evidenceText`가 원문에 그대로 존재하지 않으면 값과 근거를 제거하고 `value: null`, `evidenceText: null`, `status: not_found`으로 반환합니다.
- Gemini 구조화 결과는 날짜 형식, 숫자·단위, 좌우, 분자·분모, 교육용 필수항목 누락 규칙으로 다시 검수합니다. 위탁검사는 검사번호·검사명·검체명·날짜·결과를 가상 내부 의뢰정보와 다시 비교합니다.
- 교육용 PDF·이미지 Gemini 재추출은 서버의 `POST /api/referral/gemini-extract`에서만 실행하며, 데모 모드 또는 API 실패 시 사전 추출값을 Gemini 성공 결과처럼 반환하지 않습니다.
- pT, pN, pM, Stage는 원문에 명시된 문자열만 추출하며 병기를 계산하지 않습니다.
- IASLC/AJCC 폐암 TNM 9판 자료는 pN2a·pN2b·pM1c1·pM1c2 등의 문자열 형식 검수에만 사용하며, 종양 크기·침범·전이 정보에서 병기를 산출하지 않습니다.
- AI 결과와 담당자 수정값은 별도의 React 상태로 유지합니다.
- 담당자 확인 전 자동 저장·자동 확정하지 않습니다.
- Gemini 호출 실패 시 HTTP 오류를 반환하고 규칙 기반 결과를 Gemini 성공 응답처럼 표시하지 않습니다.

## 중요 누락·불일치 대응

- 이 서비스에서 중대 오류(blocking error) 또는 위음성(false negative) 위험은 원문에 존재하는 중요한 누락·불일치가 경고 없이 넘어가는 경우를 뜻합니다.
- 좌우 충돌, 숫자·단위, 검체 수·블록 수, 교육용 필수항목 누락, 위탁검사 의뢰번호·검사명·검체명 불일치는 원문 근거와 규칙 기반 대조로 다시 확인합니다.
- 양성·음성, 좌우, pT/pN/pM·Stage, 크기·단위, 절제연, 림프절, 면역표지자·유전자 결과, 검사번호·검체명은 자동수정하지 않고 원문 확인 상태로 남깁니다.
- 이 검수 장치는 중요한 오류를 자동으로 해결하거나 위음성을 0으로 보장하지 않습니다. 오류 미탐률은 전체 평가를 실제로 실행해 측정하기 전까지 수치로 표현하지 않습니다.

`PATHOSCRIBE_DEMO_MODE=true`인 경우에만 명시적으로 `안전 데모`라고 표시된 로컬 규칙 엔진을 사용합니다.

## v1.1 용어 검수 안전장치

- 의학용어 검수 런타임은 `lib/medical-term-review.ts`의 로컬 용어목록을 사용합니다. 암정보사전 스냅샷, 폐암 세부진단·면역병리 참고 데이터, 레지스트리 메타정보, 서비스 자체 목록을 합쳐 후보를 만들며 사용자 입력을 외부 용어 API로 전송하지 않습니다. 배포 빌드에서만 공식 암정보사전 OPEN API를 동기화합니다.
- 용어는 NFKC·대소문자·공백을 정규화한 뒤 정확 일치와 제한된 편집거리 후보를 계산합니다. 후보가 없으면 `not_found`와 `needs_review`로 표시합니다.
- 단순 철자 후보는 `pending` 상태로 제시하지만 담당자가 **제안 적용**을 눌러야 확정값에 반영됩니다. 원문과 AI 추출값은 변경하지 않습니다.
- 양성·음성, 좌우, pT/pN/pM·Stage, 종양 크기·단위, 절제연, 림프절 분자·분모, EGFR·ALK·KRAS, TTF-1·p40·PD-L1, 검사번호·검체명은 고위험으로 분류합니다. 고위험 불일치에는 확정적 수정값을 제시하지 않고 원문 확인만 요구합니다.
- 담당자 확정값의 선택 후보는 교육용 입력 보조이며 의료 표준 코드나 판정 규칙이 아닙니다. 한글·영어는 하나의 병기 메뉴값으로 표시하지만 원문 확인 없이 표준화하지 않습니다. 좌우·절제연·pT/pN/pM·Stage에는 `기타 직접 입력`을 제공하지 않고, 원문에서 추출된 값 또는 `확인 필요`만 선택할 수 있습니다.
- 원문 값이 `null` 또는 `not_found`이면 후보 선택을 제공하지 않습니다. 빈 확정값과 원문 확인 안내만 표시하여, AI가 찾지 못한 값을 선택 목록에서 보완하는 경로를 차단합니다.
- v1.1은 별도의 Gemini 호출을 추가하지 않습니다. 기존 분석 응답의 `evidenceText`를 근거로 표시하고, 용어 후보·위험도 판정은 결정론적 규칙으로 수행합니다. 따라서 용어 패널은 진단·병기·검사 결과를 생성하지 않습니다.
- 승인 상태는 `pending`, `accepted`, `rejected`, `manually_edited`, `needs_review`이며 세션 화면 상태로만 유지됩니다. 실제 개인정보나 사용자 식별정보는 저장하지 않습니다.
- 제안 적용·원문 유지·확인 필요는 첫 결정을 잠근 뒤 같은 제안의 중복 클릭을 차단합니다. 직접 수정은 사용자가 확정값을 다시 편집할 수 있도록 별도 상태로 유지합니다.

## RAG 원칙

검색 대상은 다음 로컬 근거로 제한합니다.

- 국가암지식정보센터 암정보사전 고정 스냅샷
- 폐암 레지스트리 메타정보 데이터 사전
- 프로젝트 자체 입력 형식 지침
- 교육용 병리업무 흐름
- 개인정보 없는 가상 오류 사례
- AI 안전정책과 AJCC·TNM 입력 검수 범위

답변은 검색된 근거 구절만 사용하고 문서명, 제공기관, 항목 ID, 로컬 파일 또는 공식 출처를 함께 표시합니다. 검색 결과가 없으면 `answer: null`을 반환하며 Gemini로 내용을 보완하지 않습니다.

## 개인정보와 비밀키

- 주민등록번호, 전화번호, 이메일, 환자번호 형태를 서버 요청 전에 차단합니다.
- 실제 환자정보 입력을 금지합니다.
- 질문과 결과를 데이터베이스, 로컬 저장소 또는 애플리케이션 로그에 저장하지 않습니다.
- `.env`는 Git에서 제외합니다.
- `GEMINI_API_KEY`와 공공데이터 키에 `NEXT_PUBLIC_` 접두사를 사용하지 않습니다.
- 실제 키 값을 로그, 응답, 문서, 클라이언트 번들에 포함하지 않습니다.

## 의료적 제한

IASLC/AJCC 폐암 TNM 9판 교육용 참조는 형식 검수 범위에 한정합니다. 공식 기준문서가 제공되지 않은 병기 조합 규칙이나 기관별 입력 규칙은 구현하지 않습니다. 최종 진단과 병기 판정은 병리의사가 수행하며 PathoScribe는 교육용 입력 검수 도구입니다.
