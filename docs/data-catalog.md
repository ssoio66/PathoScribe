# PathoScribe 데이터 카탈로그

기준: 2026-08-25 현재 프로젝트 폴더에 저장되었거나 코드상 연결된 데이터입니다. API 키 값은 문서화하지 않으며, 공공 집계 API는 환자별 결과 데이터처럼 사용하지 않습니다.

## v1.1 용어 검수 연결

병리 결과 화면의 용어 검수는 새 외부 의학용어 API를 호출하지 않습니다. 다음 로컬 자료를 합쳐 후보 목록을 구성합니다.

| 자료 | 데이터 성격 | v1.1 활용 |
| --- | --- | --- |
| 암정보사전 고정 스냅샷 | 공개 용어 설명 스냅샷, 개인별 결과 아님 | 한글·영문 용어와 별칭 후보, 출처 표시 |
| 폐암 세부진단 종류별 API | 공공 집계 데이터, 개인별 진단 아님 | 진단명 참고 후보와 용어 범주 |
| 폐암 면역병리 종류별 API | 공공 집계 데이터, 개인별 검사 결과 아님 | TTF-1·p40·CK7·PD-L1 등 검사명 참고 |
| 폐암 레지스트리 메타정보 CSV | 테이블·컬럼 정의 메타정보 | 구조화 필드 범주와 데이터 항목명 참고 |
| 프로젝트 자체 데이터 사전·평가사례 용어 | 서비스 생성 교육용 자료 | 병리 입력 용어와 오류 사례 보완 |

Gemini는 기존 구조화 응답에서 원문 근거와 의미 문맥을 제공하고, 용어 후보·편집거리·위험도 판정은 서버의 로컬 규칙이 수행합니다. 용어목록에 없는 표현은 `확인 필요`로 표시하며 위 자료를 환자별 병리 결과나 진단 근거로 사용하지 않습니다.

## 상세 카탈로그

### 1. 국립암센터 암 임상 라이브러리 합성데이터 (폐암)

- 제공기관: 국립암센터
- 로컬 파일 위치 또는 API Route: `data/raw/ncc-lung-synthetic-20250107.zip`, `data/processed/ncc-lung-linkage-summary.json`, `data/generated/*.json`
- 파일 형식: ZIP 내부 XLSX, 처리 JSON
- 데이터 건수: 원본 XLSX 15,000행(훈련 10,000행, 테스트 5,000행), 34개 컬럼
- 갱신 방식: 사용자 제공 ZIP을 로컬에 보관하고 `npm.cmd run data:sync:lung-linkage`, `npm.cmd run data:generate:pathology-workflow`로 처리본 재생성
- 개인별 데이터인지 집계데이터인지: 개별 환자가 아닌 폐암 합성 레코드 단위
- 실제 공개데이터인지 프로젝트 생성 가상데이터인지: 실제 공개 합성데이터
- 사용 화면: 품질 대시보드, 가상 연결 데이터
- 사용 목적: 조직형 플래그, 병기 플래그, EGFR 값 등 공개 합성 변수로 데이터 품질 지표와 가상 병리 업무 흐름 구성
- 한계: 실제 환자데이터가 아니며 육안 소견·병리 판독 원문·검체·블록·보고서 ID가 없습니다. 연결 ID는 모두 프로젝트 가상 ID입니다.
- 출처 URL: `https://www.data.go.kr/`
- 기준일: 2025-01-07

### 2. 폐암 라이브러리 세부진단 종류별 API

- 제공기관: 국립암센터
- 로컬 파일 위치 또는 API Route: `data/processed/ncc-lung-diagnosis-reference.json`, `/api/reference-diagnoses`
- 파일 형식: 공공 API JSON 처리 스냅샷
- 데이터 건수: API 집계행 3,213개, 고유 통계 대상 74개
- 갱신 방식: `npm.cmd run data:sync:diagnoses` 실행 시 서버 전용 API 키로 재수집
- 개인별 데이터인지 집계데이터인지: 센터·연도 등 조건으로 조회한 공공 집계 데이터
- 실제 공개데이터인지 프로젝트 생성 가상데이터인지: 공공 API 스냅샷
- 사용 화면: 병리 결과 구조화 및 검수, 데이터 출처
- 사용 목적: 입력된 가상 진단명 문자열의 참고 후보와 로컬 용어 검수 범주를 확인
- 한계: 표준 진단 사전, 확정 진단 코드, 환자별 병리 결과가 아닙니다. 자동 입력이나 진단 확정 근거로 사용하지 않습니다.
- 출처 URL: `https://www.data.go.kr/data/15077056/openapi.do`
- 기준일: 스냅샷 2026-08-22, 조회 범위 2010-2019

### 7. 국가암지식정보센터 암정보사전 고정 스냅샷

- 제공기관: 국가암지식정보센터
- 로컬 파일 위치 또는 API Route: `data/raw/cancer-dictionary-source.json`, `data/processed/cancer-dictionary-rag.json`, `/api/knowledge/search`, `/api/knowledge/browse`
- 파일 형식: 사용자 제공 JSON/HTML 스냅샷, RAG용 처리 JSON
- 데이터 건수: 용어 3,544개
- 갱신 방식: 사용자 제공 스냅샷을 `npm.cmd run data:sync:cancer-dictionary`로 정규화
- 개인별 데이터인지 집계데이터인지: 용어 설명 항목 단위
- 실제 공개데이터인지 프로젝트 생성 가상데이터인지: 실제 공개데이터의 고정 스냅샷

## 안전 해석 원칙

- 공공 집계 API를 환자별 결과 데이터처럼 사용하지 않습니다.
- 합성데이터를 실제 환자데이터라고 표현하지 않습니다.
- 메타정보 CSV를 실제 병리 결과라고 표현하지 않습니다.
- 데이터 파일에 없는 컬럼을 원본 컬럼이라고 주장하지 않습니다.
- API 호출에 실패했을 때 임의 데이터를 실제 응답처럼 표시하지 않습니다.
- 고정 스냅샷을 사용하는 자료는 스냅샷 기준일을 표시합니다.
