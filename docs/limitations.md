# 현재 한계

## 외부 연동

- 전체 Gemini 평가는 고정 교육용 35건을 대상으로 한 로컬 개발환경 전용 실행기만 구현되어 있습니다. 실제 35건 일괄 실행 결과와 지표는 명시적 승인 후에만 생성되며, 실행 전에는 성능 수치를 표시하지 않습니다.
- 기관지내시경검사 API는 공개 집계 스냅샷으로 연결했지만, 개별 검사 이력·검체 채취 방법·조직채취 사실을 제공하지 않으므로 가상 사례에 환자별로 매칭하지 않습니다.
- 공공 API 스냅샷은 고정 자료이며 자동 갱신하지 않습니다.

## 문서·음성 처리

- 위탁검사 PDF 9개·PNG 1개는 평가 ground truth에서 파생한 등록 교육용 fixture와 사전 검증된 추출 JSON을 비교합니다. 모든 파일에 `교육용 가상자료·실제 의료기록 아님` 워터마크가 있으며, 임의 PDF·이미지의 실제 업로드 전송, OCR, 문서 구조 분석은 구현하지 않았습니다.
- 등록된 교육용 fixture에는 Gemini 문서 재추출 Route가 준비되어 있지만, 현재 데모 모드에서는 의도적으로 실행하지 않습니다. 실제 Gemini 생성 endpoint가 정상화되기 전에는 이 경로의 성공 결과를 검증하거나 성능으로 주장할 수 없습니다.
- 평가 사례 화면의 자동 대조는 한 사례를 실행한 뒤 보이는 필드 단위 상태 표시입니다. 전체 실행기는 Gemini+규칙 하이브리드 결과만 측정하며, 규칙 기반 단독 및 Gemini 단독 비교는 실제로 별도 실행하기 전까지 N/A로 표시합니다.
- 음성인식 엔진과 의학용어 음성 불확실성 탐지는 구현하지 않았습니다. 음성 전사문 형태의 텍스트만 입력할 수 있습니다.
- PDF 저장은 서버 생성 기능이 아니라 브라우저 인쇄 대화상자를 사용합니다.

## 데이터

- 국립암센터 XLSX는 공개 합성데이터이지만 자유서술 육안 소견이나 병리보고서 원문, 검사·검체·블록 ID를 포함하지 않습니다.
- `ORD/SPC/GRS/BLK/RPT/IHC/MOL/EXT/REV` ID와 자유서술 예시는 시제품용 생성값입니다.
- 폐암 레지스트리 CSV는 환자 결과가 아니라 253개 필드의 메타정보입니다.
- 집계 API를 개인 진단, 검사 결과, 병기 또는 치료 판단에 사용하지 않습니다.
- 암정보사전 목차의 폐·흉부/병리·조직/면역·표지자/분자·유전 분류는 문자열 키워드 기반 교육용 탐색 분류입니다. 공식 의학 분류가 아니며 한 용어가 여러 분류에 포함될 수 있습니다.
- 암정보사전 원본과 처리 스냅샷은 Git에서 제외합니다. 배포 빌드는 국가암지식정보센터 공식 OPEN API를 호출해 정제본을 생성하므로, 공식 API가 일시적으로 응답하지 않으면 누락된 사전으로 배포하지 않고 빌드가 실패합니다.
- IASLC/AJCC 폐암 TNM 9판 교육용 참조는 문자열 형식 검수에만 반영했습니다. 기관별 병리 입력 지침과 자동 병기 조합 규칙은 구현하지 않았습니다.
- 생성한 연결 데이터는 실제 임상 관계가 아니라 화면 흐름을 시연하기 위한 가상 연결입니다.

## 병원·의료 기능

- 실제 의료기관의 로고, 화면, 내부 지침, 문서 양식, 권한체계 또는 정보시스템을 사용하지 않습니다.

## v1.1 용어 검수 범위

- 용어목록은 로컬 고정 스냅샷 또는 배포 빌드 시 공식 OPEN API에서 동기화한 스냅샷과 서비스 자료로 구성한 교육용 목록입니다. 모든 의학용어와 변형을 포괄한다고 보장하지 않습니다.
- 편집거리 후보는 단순 철자 오류 탐지용이며 문맥상 정확한 진단명이나 검사 결과를 판정하지 않습니다.
- 고위험 필드는 자동수정·확정 제안을 하지 않고 원문 확인 상태로 남깁니다. 낮은 위험 후보도 담당자 승인 전에는 확정값이 아닙니다.
- 확정값 선택 후보는 프로젝트가 보유한 교육용 용어와 평가사례 표현을 보조적으로 정리한 것이며, 한글·영어 병기는 표시 편의를 위한 것입니다. 모든 폐암 병리 표현이나 공식 입력 코드를 포괄하지 않습니다.
- `null`·`not_found` 항목은 후보 메뉴 없이 빈 자유 입력으로 표시합니다. 빈 값은 정보가 없다는 뜻이므로 담당자가 원문을 확인하기 전에는 확정값으로 볼 수 없습니다.
- 승인·직접수정 상태는 브라우저 세션에만 유지되며 영구 감사로그나 사용자 식별정보 저장 기능은 제공하지 않습니다.
- 실제 인증, 실제 전자서명, PIS/EMR/LIS 연동, 공식 의료기록 저장 기능이 없습니다.
- 병리의사를 대신하는 진단·판독·병기 판정 기능이 없습니다.

## 중요 오류 검수의 한계

- 원문 근거, 규칙 기반 대조, 고위험 자동수정 차단은 좌우·숫자·단위·필수항목·검사 연결의 중요 불일치가 경고 없이 넘어갈 위험을 줄이기 위한 장치입니다.
- 이 장치가 모든 중대 오류(blocking error) 또는 위음성(false negative)을 탐지하거나 오류 미탐률을 0으로 만든다고 보장하지 않습니다.
- 실제 오류 미탐률은 35건 전체 평가를 실제 Gemini로 실행해 계산하기 전까지 측정값으로 제시하지 않습니다.

## 검증 한계

- 현재 실행 환경에 제어 가능한 브라우저가 없어 모든 버튼·링크의 실제 클릭, 브라우저 인쇄 대화상자, 키보드 이동, 모바일·태블릿·PC 스크린샷 검증은 수행하지 못했습니다.
- 반응형 CSS, 초점 표시, 스킵 링크, ARIA 이름과 탭 패널 관계는 정적 코드 검토와 lint/build로 확인했습니다. 실제 브라우저와 보조기술 수동 검증이 추가로 필요합니다.
- 외부 출처 링크는 제공기관의 주소 변경이나 접근 제한에 따라 열리지 않을 수 있습니다.
