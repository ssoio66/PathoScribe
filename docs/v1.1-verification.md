# PathoScribe v1.1 회귀 검증

검증일: 2026-08-26

## 범위

기존 10단계 문서를 다시 작성한 것이 아니라, v1.1의 병리 결과 구조화 입력 템플릿·의학용어 오탈자 검수·수정 제안 승인 흐름과 영향을 받는 기존 API·가상자료·보안을 재검증했다. 전체 35건 Gemini 평가는 실행하지 않았고 production build에서도 호출되지 않았다.

## 작업 목록-평가사례 연결 보완

- 검증일: 2026-08-26
- 작업 목록은 `source_record_id`와 평가사례 `sourceRowId`가 정확히 일치한 경우에만 해당 업무 유형과 `EVAL-...` 사례를 연다.
- 생성 미리보기 48건 중 평가사례와 연결된 35건을 우선 포함한다. 나머지 13건은 연결되지 않은 행으로 표시하며 임의의 평가사례를 열지 않는다.
- 검증: `npm.cmd run test:worklist-links` 통과, `/api/evaluation/cases?sourceRowId=NCC-LUNG-TST-00000` 조회 통과, typecheck·lint·정상/오류 회귀·웹 통합·production build 통과.
- 브라우저 자동화 환경이 없어 실제 클릭 시각 검증은 미실행이다. 로컬 개발 서버의 HTTP 200 응답은 확인했다.

## 전체 평가 상태

35건 전체 Gemini 평가는 실행하지 않았다. 실행할 경우 예상 호출은 35회다. v1.1 성능 확장 항목은 오탈자 후보 탐지, 정상 용어 오탐, 잘못된 후보, 고위험 자동수정 차단이다. 사용자 승인 상태는 Gemini 성능이 아니라 로컬 UI 상태 전이 테스트로 분리해야 한다.

## v1.1 오류 비교값 표시

오류 사례의 영향 필드는 경고에 연결된 모든 필드의 현재 추출값을 함께 표시합니다. 현재값이 기준값과 다를 때만 기준값을 괄호로 추가하고, 각 필드의 원문 근거를 함께 보여 주어 좌우·검사정보·수치 등 다중 필드 충돌을 화면에서 확인할 수 있습니다. 정상 사례와 원문 추출 정답 대조에는 영향을 주지 않습니다.

검증: `npm.cmd run test:normal-cases`, `npm.cmd run test:error-cases`, `npm.cmd run test:web`, `npm.cmd run test:v1.1`, `npm.cmd test`, `npm.cmd run typecheck`, `npm.cmd run lint`, `npm.cmd run build` 통과.
