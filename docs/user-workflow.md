# PathoScribe 사용자 업무 흐름

## 기본 사용자

기본 역할은 보건의료정보관리사입니다. 역할별 화면 보기는 실제 병원 인증이나 권한체계가 아니라 교육용 시제품에서 화면 관점을 설명하기 위한 선택기입니다.

## 1. 육안 소견 입력·검수

1. `육안 소견` 화면을 엽니다.
2. 개인정보가 없는 가상 원문임을 확인합니다.
3. 가상 육안 소견 또는 음성 전사문 형태의 텍스트를 입력합니다.
4. `AI 초안 생성`을 눌러 장기, 검체, 부위, 좌우, 크기, 개수, 절단면, 병변 위치, 블록 수를 구조화합니다.
5. 각 항목에서 원문 근거, 추출값, 담당자 입력값을 비교합니다.
6. 원문에 값이 없으면 `null`로 유지합니다. 원문 안에서 좌우값이 충돌하거나 검사명만 있고 결과가 없으면 발견한 원문 표현을 보존한 채 `확인 필요`로 표시합니다.
7. 담당자가 직접 값을 수정하고 `검수 완료 표시`를 누릅니다. 이 표시는 브라우저 세션에만 남으며 의료기록을 저장하지 않습니다.
8. 필요한 경우 브라우저 인쇄 기능으로 교육용 검수 화면을 PDF로 저장합니다.

중요한 누락·불일치는 자동으로 해결하거나 확정하지 않습니다. 좌우 충돌, 숫자·단위, 교육용 필수항목 누락은 원문 근거와 규칙 검수로 다시 표시하며, 담당자는 `원문 확인 필요` 상태를 확인한 뒤 확정값을 작성합니다.

## 2. 병리 결과 입력·검수

1. `결과 구조화·검수` 화면을 엽니다.
2. 개인정보 없는 가상 병리 결과문을 입력합니다.
3. 장기, 검체, 조직학적 진단명·유형, 종양 크기, 분화도, 절제연, 림프절, 원문 병기 문자열, 면역병리·분자병리 결과를 확인합니다.
4. pT, pN, pM, Stage는 원문에 적힌 문자열만 표시합니다. IASLC/AJCC 폐암 TNM 9판 교육용 참조로 `pN2a`, `pN2b`, `pM1c1`, `pM1c2` 등의 형식만 확인하며, 조합 계산이나 최종 병기 산출은 하지 않습니다.
5. 세부진단·면역병리·병기 API 정보는 집계 참고와 입력 형식 확인에만 사용합니다.
6. 담당자가 원문과 비교해 수정하고 검수 완료 상태를 표시합니다.

가상 연결 데이터 화면에서는 동일한 `report_id`에 연결된 원본 합성 XLSX의 T/N/M 플래그, 원본 행 ID, 값 출처 구분을 확인할 수 있습니다. 이 플래그는 9판으로 재분류하지 않으며, IASLC/AJCC 9판 자료는 원문 병기 문자열 형식의 교육용 참고로만 별도 표시합니다.

## 3. 위탁검사 결과 입력·매칭

1. `위탁검사 입력` 화면을 엽니다.
2. 등록된 교육용 PDF·이미지 fixture를 선택하거나 같은 파일명의 가상 자료를 선택합니다.
3. 가상 의뢰번호, 검사기관, 검사명, 검체, 접수일, 보고일, 수정 보고서 상태, 결과, 참고사항을 내부 가상 의뢰정보와 비교합니다.
4. 각 항목의 `일치`, `불일치`, `확인 필요` 상태를 확인합니다.
5. 담당자가 원문을 대조한 뒤 확인 상태만 표시합니다. 결과는 자동 저장하거나 확정하지 않습니다.

현재 구현은 실제 PDF·이미지 바이트를 OCR하는 업로드 기능이 아니라 등록된 9개 PDF·1개 PNG fixture와 평가 ground truth에서 파생한 추출 JSON을 비교하는 시연입니다. 모든 파일에는 `교육용 가상자료·실제 의료기록 아님` 워터마크가 있습니다.

## 보조 화면

- `검수 작업 목록`: 공개 합성데이터를 기반으로 만든 가상 작업을 표시합니다. `source_record_id`와 평가사례 `sourceRowId`가 정확히 일치할 때만 같은 `EVAL-...` 사례와 업무 유형 화면을 엽니다. 연결이 없으면 임의의 사례를 불러오지 않고 해당 가상 주문의 연결 데이터 화면을 엽니다.
- `가상 연결 데이터`: 검사 의뢰부터 검수 완료까지 가상 ID로 연결된 사례를 탐색합니다.
- `품질 대시보드`: 합성데이터 현황과 현재 브라우저 세션의 비식별 오류 유형을 표시합니다.
- `용어·입력 지침`: 등록된 로컬 근거 안에서만 답변하고 문서명과 근거 구절을 표시합니다. 자유 검색 외에 `목차 탐색`에서 암정보사전 3,544개 용어를 40개씩 페이지로 열람하고, 용어를 선택해 동일한 근거 검색 결과를 확인할 수 있습니다. 화면 분류는 공식 의학 분류체계가 아닌 교육용 키워드 분류입니다.
- `데이터 출처`: 공개 합성데이터, 집계 API, 메타정보, 프로젝트 생성 가상자료를 구분합니다.

모든 화면은 실제 환자정보 입력 금지, 교육용 시제품, 담당자 원문 대조 필요 원칙을 따릅니다.

## v1.1 병리 결과 구조화·용어 검수

병리 결과 화면에는 기존 원문·AI 추출·검수 결과 영역 안에 다음 보조 흐름이 추가됩니다.

1. 평가 사례를 불러오고 가상 원문을 분석합니다.
2. AI가 원문에서 찾은 값은 **구조화 입력 템플릿**에 배치됩니다. 템플릿은 검체, 장기, 좌우·부위, 시술·수술, 진단, 조직학적 유형, 종양 크기, 분화도, 절제연, 림프절, 면역병리, 분자병리, 원문 병기 필드를 제공합니다.
3. AI 추출값과 템플릿 값은 담당자 확정값과 별도로 유지됩니다. 값이 없으면 빈 값 또는 `확인 필요`로 남습니다.
4. 로컬 용어목록이 정상 용어, 단순 오탈자 후보, 고위험 불일치, 사전 미등재를 구분합니다. 후보에는 원문 근거와 출처가 함께 표시됩니다.
5. 담당자 확정값은 항목별로 입력 방식을 구분합니다. 장기·부위·시술·진단·유형·분화도는 `우측 (right)`, `선암 (adenocarcinoma)`처럼 한글·영어를 하나의 메뉴값으로 병기한 교육용 선택 후보와 `기타 직접 입력`을 제공하며, 크기·림프절처럼 복합 표기가 필요한 값은 원문 표기를 직접 입력합니다.
6. 원문 값이 `null` 또는 `not_found`이면 어떤 항목이든 선택 후보와 `기타`를 숨기고, 빈 자유 입력칸으로 둡니다. 직군에 따라 입력 가능 여부만 달라지며, 원문 확인 전에는 확정하지 않습니다.
7. 좌우·절제연·pT/pN/pM·Stage는 고위험 정보이므로 값이 있을 때에도 `기타` 입력을 제공하지 않습니다. 원문에서 추출된 값만 직접 선택하거나 `확인 필요`로 남기며, 선택 자체는 담당자 확인을 대신하지 않습니다.
8. 낮은 위험의 단순 오탈자만 **제안 적용**할 수 있습니다. 적용값은 담당자 확정값에만 복사되며 원문·AI 값은 변경되지 않습니다. 원문 유지, 직접 수정, 확인 필요 상태도 별도로 기록합니다.
8. 좌우, 양성·음성, 병기, 크기·단위, 절제연, 림프절, 유전자·면역표지자, 검사번호·검체명은 자동 수정하지 않습니다. 해당 항목에는 “중요 의료정보의 불일치 가능성이 있어 자동수정하지 않았습니다. 원문을 확인해 주세요.”를 표시합니다.
9. 제안 적용·원문 유지·확인 필요 중 하나를 선택하면 같은 제안의 결정 버튼은 다시 실행되지 않습니다. 담당자 확정값 입력란의 직접 수정은 계속 가능하며 원문에는 반영되지 않습니다.

육안 소견 화면에서는 같은 로컬 검수 패널을 용어·숫자·좌우·단위·검체 수 확인 범위로 사용합니다. 위탁검사 화면은 검사명·검체명 표기를 내부 가상 의뢰정보와 비교할 뿐 자동 수정하지 않습니다.
## 평가 사례로 즉시 시연

1. 보건의료정보관리사 역할에서 `육안 소견 입력` 또는 `병리 결과 입력`을 엽니다.
2. 첫 정상 사례가 자동으로 원문 입력칸에 채워집니다. 다른 정상·오류 사례는 `평가 사례 불러오기` 선택기에서 고릅니다.
3. `AI 구조화 분석 실행`을 누릅니다. Gemini 연결이 가능한 설정이면 서버의 Gemini Route를 호출하고, 데모 모드이면 화면에 `교육 데모`로 분명히 표시된 규칙 기반 결과를 표시합니다.
4. 각 항목의 원문 근거, AI 추출값, 원문 추출 정답, 담당자 확정값을 대조합니다. 오류 사례에서 원문 추출이 일치해도 오류가 없다는 뜻은 아닙니다. 오류 영향 필드에는 경고에 연결된 모든 필드의 `현재값`, 필요할 때 `기준값`, 원문 근거, 오류 탐지 상태를 인라인으로 표시하고, 별도의 `오류 검수 재현`에서 기준값 불일치 탐지 여부를 다시 표시합니다.
5. 담당자 확정값을 수정하고 검수 완료 상태를 표시하거나, 브라우저 인쇄로 교육용 검수 결과를 PDF로 저장합니다. 확정 상태는 브라우저 세션 밖으로 저장되지 않습니다.

위탁검사 입력 화면도 첫 정상 일치 fixture를 기본 선택합니다. 다른 fixture를 선택하면 해당 가상 PDF·이미지 파일명과 워터마크가 자동 입력되며, `원본 가상 문서 열기`에서 공개된 교육용 파일을 확인한 뒤 대조를 실행합니다. 이 기능은 등록된 fixture의 사전 검증 추출값을 내부 가상 의뢰정보와 비교하는 시연이며, 임의 업로드 파일의 OCR이나 문서 분석 기능은 아닙니다.
