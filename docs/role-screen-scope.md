# 역할별 화면 범위

PathoScribe의 역할 선택은 교육용 시제품에서 업무 관점을 보여 주는 UI 기능입니다. 실제 의료기관 인증, 사용자 계정, 서버 권한 검증 또는 실제 권한체계를 구현하지 않습니다.

최초 진입 시에는 역할을 미선택으로 두고 `서비스 소개`, `업무 시연`, `서비스 설명`의 기본 메뉴와 사이드바의 역할 선택기를 표시합니다. `업무 시연`의 역할 카드 또는 사이드바 선택기에서 역할을 선택하면 해당 직군의 기본 화면과 역할별 메뉴가 열립니다. 역할별 업무 화면에서는 역할 범위를 기본 접힌 요약으로 표시하며, `역할 범위 자세히 보기`를 선택했을 때만 수정·조회 범위와 주요 화면 이동을 펼칩니다.

## 공통

- 서비스 소개
- 업무 시연
- 서비스 설명
- 데이터 출처
- 안전·데이터 정보
- 실제 환자정보 입력 금지 및 교육용 시제품 고지

## 보건의료정보관리사

- 작업목록, 육안 소견 입력·검수, 병리 결과 입력·검수, 위탁검사 결과 매칭, 검수 이력, 용어·입력 지침
- 가상 원문 입력, AI 구조화 결과 대조, 담당자 확정값 수정, 교육용 PDF 저장 가능

## 병리의사

- 검토 요청 목록, 병리 결과 검토, 사례 연결 타임라인, 검토 이력, 용어·입력 지침
- 원문과 구조화 결과를 조회하고 교육용 수정 요청 상태만 표시 가능
- 담당자 확정값 수정, 실제 전자서명, 임상적 최종 승인, 공식 판독 저장은 제공하지 않음

## 임상병리사·병리 검사 담당자

- 작업목록, 검사·검체·블록 연결, 면역병리·분자병리 상태, 위탁검사 대조 상태, 용어·입력 지침
- 병리 진단문, 담당자 확정값, 검토 완료 상태를 수정할 수 없음

## 품질관리자

- 비식별 품질 대시보드, 오류 유형 집계, 검수 이력 요약, 데이터 출처
- 개별 원문, 개별 확정값, 사례 단위 추적, 사용자별 실제 성과 평가는 제공하지 않음

## 구현 한계

사이드바 필터링과 작성·조회 버튼 제한은 브라우저 UI 수준의 시제품 구현입니다. 실제 의료기관 환경에서는 서버 인증, API 인가, 데이터 행 단위 권한, 감사 로그를 별도로 구현해야 합니다.
